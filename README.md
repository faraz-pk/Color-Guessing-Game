# 🎨 Color Guessing Game

A fun and interactive Color Guessing Game built using HTML, CSS, and JavaScript.
Test your color recognition skills by guessing the correct color based on the displayed RGB value.

---

## 📌 Features

* Random color generation
* Interactive gameplay
* RGB color guessing challenge
* Responsive design
* Simple and clean UI
* Instant result feedback

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
